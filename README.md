# HR-Analytics-Absenteeism-Dashboard

### This project analyzes employee absenteeism data to uncover patterns and insights that can support better HR decision-making.

## Project Overview

### The goal of this project was to explore how absenteeism varies across time, workload, and employee characteristics, and to present the findings in a clear and interactive dashboard.

## Tools Used

- SQL – data querying, filtering, and transformation

- Power BI – data modeling and dashboard development

## Data Processing

- Performed data cleaning to handle missing values and inconsistencies

- Transformed raw data using SQL to prepare it for analysis

- Created calculated measures and visuals in Power BI

## Key Analysis Areas

- Average and total absenteeism time

- Absenteeism by day of the week and month

- Relationship between workload and absenteeism

- Absence reasons and employee lifestyle factors

## Outcome

The dashboard provides a consolidated view of absenteeism trends and highlights areas where organizations can take proactive steps to reduce time lost and improve workforce efficiency.
